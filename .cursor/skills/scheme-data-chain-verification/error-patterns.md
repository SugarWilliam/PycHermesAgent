# 常见错误模式详析与防护

## P1：DDR容量命名混淆

### 表现
将 "DDR3 2+1" 错误理解为 3 片 DDR3（2×2Gb + 1×1Gb = 640MB），而非正确的 2 片（2Gb + 1Gb = 384MB）。

### 本对话案例
- 报告多次出现 DDR3 2+1=640MB，Media分配384/256MB
- 用户反复纠正："DDR3 1+1 是指 1GbDDR3 + 1GbDDR3, DDR3 2+1 是指2GbDDR3 + 1GbDDR3"
- 最终修正为 384MB，Media 256/128MB

### 防护
1. **每次提到DDR配置时写出换算**：`DDR3 2+1 = 2Gb + 1Gb = 3Gb = 384MB`
2. **查 [ddr-naming-rules.md](ddr-naming-rules.md) 标准配置表**
3. **Media+OS之和强制校验等于总容量**

---

## P2：加权增长因子算术错误

### 表现
在计算加权增长因子时，某一项的乘法结果写入错误（跳步心算），导致最终因子从正确的 1.22 变成 1.15。

### 本对话案例
```
正确计算: 0.40×1.39 + 0.02×1.0 + 0.58×1.11
        = 0.556 + 0.020 + 0.6438
        = 1.2198 → 1.22

错误计算: ... + 0.58×1.11 = ... + 0.58? (正确应是0.6438)
         → 1.15  ❌
```

连锁影响：Media峰值占用从142.18MB变成134.02MB（错8.16MB），所有余量数据偏差。

### 防护
1. **禁止跳步心算**，必须写出每个中间项
2. **加权增长因子展开式逐项验证**
3. **用简单比例交叉验证**：像素带宽增长1.11，前端管线增长1.39，加权结果应在1.11-1.39之间

---

## P3：像素带宽数值不统一

### 表现
同一数值在不同章节出现不同圆整结果。如 314MP/s 与 315MP/s 并存于报告。

### 本对话案例
- 15.7MP × 20fps = 314.57MP/s
- 有些位置写314，有些写315
- C1修正：统一为315MP/s，超出5.0%

### 防护
1. **选择一个圆整值并全报告统一**
2. **grep 所有可能变体**（314、315、4.7%、5.0%）确认无残留
3. **正文每一处引用该数字时都用同一个值**

---

## P4：边表锚点与正文机制矛盾

### 表现
R109边表中的锚点描述了一种推算逻辑，但正文中对同一主题的解释使用了不同的（正确的）机制。

### 本对话案例
```
边表: "4倍像素外推：30fps→7-8fps" (暗示无binning的线性外推)
正文: "binning-mode下仍处理4MP，帧率约25-30fps"
→ 边表锚点描述的是"如果没有binning-mode"的错误假想场景
```

### 防护
1. **R109审计规则4**：边表不得出现与更高级别证据矛盾的锚点
2. **边表构建时，源/目标/锚点必须与正文使用的机制一致**
3. **机制性约束（如binning-mode）必须在边表中作为L1边被引用**

---

## P5：修正遗漏（跨章同步失败）

### 表现
修改了某个数字后，报告其他位置引用该数字的地方忘记同步更新。

### 本对话案例
- C1/C2修正后，附录B发前自检表中仍残留旧值-6.02MB
- 经全链路审计才被发现并修正

### 防护
1. **修改任何数字后立即 `grep` 旧值全报告**，确认无残留
2. **建立关键数字→位置映射表**，修改时逐位置校验
3. **执行 §3.3 跨章数字一致性校准流程**

---

## P6：Media/OS分配总和超出总容量

### 表现
给某个DDR配置分配的Media+OS之和超过总物理容量。

### 示例
```
DDR3 2+1 = 384MB（总容量）
Media 512MB + OS 128MB = 640MB > 384MB ❌
正确: Media 256MB + OS 128MB = 384MB ✅
```

### 防护
1. **每次写Media/OS分配时强制计算总和**
2. **Media分配 + OS分配 = 总容量（硬约束，不可逾越）**

---

## 综合防护策略

| 错误类型 | 检查工具 | 检查频率 |
|---------|---------|:--------:|
| DDR容量 | 查 ddr-naming-rules.md 标准表 | 每次提及 |
| 算术错误 | 展开完整算式 | 每次计算 |
| 数值不一致 | grep 全报告 | 每次修改 |
| 边表矛盾 | R109审计规则1-4 | 定稿前 |
| 修正遗漏 | grep 旧值 | 每次修改 |
| 容量超限 | Media+OS=总容量校验 | 每次分配 |
