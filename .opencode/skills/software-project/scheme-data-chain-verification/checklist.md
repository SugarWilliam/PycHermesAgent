# 方案论证验证清单（可打印/复制）

## 阶段0：数据锚点提取

```
□ 从报告中提取所有关键数字
□ 为每个数字建立锚点ID
□ 标注每个锚点的证据等级(L1-L5+)和来源
□ 标注每个锚点的可靠性Q值（L1=1.00, L5=0.60, L5+=0.85）
□ 确认所有Q<0.70的数字已标注 [待实测验证]
□ 确认所有L5推断锚点均来自L3及以上源
```

## 阶段1：逐段一致性校验

```
### DDR容量
□ DDR3 1+1 = 256MB (2×1Gb) - 全报告一致
□ DDR3 2+1 = 384MB (2Gb+1Gb) - 全报告一致
□ DDR3 2+2 = 512MB (2×2Gb) - 全报告一致
□ DDR4配置 - 区分DDR3/DDR4单位

### 编码能力
□ 标称像素带宽计算正确（MP×fps=MP/s）
□ 需求像素带宽 vs 标称超出比例正确
□ 双规格(20fps/25fps)各自评估

### 内存推算
□ 实测基准峰值占用提取正确
□ 分辨率增长因子计算正确
□ 像素带宽增长因子计算正确
□ 组件级占比有合理解释
□ 加权增长因子展开式完整且算术正确
□ 推算峰值占用 = 基准占用 × 加权增长因子
□ 各配置Media余量 = Media分配 − 推算占用
□ Media+OS之和 = 总容量（每配置校验）

### 范畴错误量纲
□ MB vs Mb换算正确（1Gb=128MB，非1024MB）
□ 带宽(MB/s)与容量(MB)未混淆
□ MP/s(编码能力)与MP(分辨率)未混淆
□ Gbit(DDR命名)与GB(总容量)未混淆

### 重算冲突
□ 同一物理量无多路径推导且数值不一致的情况
□ 若存在多值，已执行 2σ 检测并标注采纳路径
```
