# DDR容量命名规则详解

## SSOT 定义

DDR配置命名 `X+Y` 表示**双片 DDR 芯片组合**，X 和 Y 分别是两片 DDR 的容量（单位：Gbit）。

```
DDR3 X+Y = 第1片DDR3(X Gbit) + 第2片DDR3(Y Gbit)
DDR4 A×B = A片DDR4 × 每片B Gbits
```

## 标准配置表

| 配置名 | 实际组成 | 芯片数 | 总容量(Gbit) | 总容量(MB) | Media/OS典型分配 |
|--------|---------|:------:|:------------:|:-----------:|:---------------:|
| DDR3 1+1 | 1Gb + 1Gb | 2 | 2 | **256** | 128/128 |
| DDR3 2+1 | 2Gb + 1Gb | 2 | 3 | **384** | 256/128 |
| DDR3 2+2 | 2Gb + 2Gb | 2 | 4 | **512** | 256/256 |
| DDR4 双片各4Gbits | 4Gb + 4Gb | 2 | 8 | **1024（1GB）** | 512/512 |

## 常见错误及其根源

### 错误1：将 X+Y 误解为片数

```
错误理解: DDR3 2+1 = 2片2Gb + 1片1Gb = 3片 = 640MB ❌
正确理解: DDR3 2+1 = 1片2Gb + 1片1Gb = 2片 = 384MB ✅
```

**根源**：将"+"理解为"和"（加法连接多个DDR芯片），而实际是"组合"的缩写。

### 错误2：DDR3 vs DDR4 单位混淆

```
错误: DDR3 2+2 (2×2Gb=512MB) 与 DDR4 2×4Gbits (2×4Gb=1GB) 混同为同一档 ❌
正确: DDR3 2+2=512MB，DDR4双片各4Gbits=1GB，容量差一倍 ✅
```

### 错误3：Media/OS分配脱离总容量约束

```
错误: DDR3 2+1(384MB) → Media 512MB + OS 128MB = 640MB ≠ 384MB ❌
正确: DDR3 2+1(384MB) → Media 256MB + OS 128MB = 384MB ✅
```

## 防护规则

1. **每次提及DDR配置时必须写出换算过程**：
   - `DDR3 2+1：2Gb + 1Gb = 3Gb ÷ 8 × 1024 = 384MB`
2. **Media+OS分配之和 = 总容量**（强制校验，不得逾越）
3. **DDR3和DDR4分别标注单位**（Gbit vs Gbits，避免混淆）
4. **任何新配置出现时，首先查本表确认是否有定义**

## 扩展命名

若有其他DDR组合，按此模板扩展：

| 配置名 | 组成 | Gbit | MB |
|--------|------|:----:|:--:|
| DDR3 4+2 | 4Gb+2Gb | 6 | 768 |
| DDR4 单8Gbits | 1×8Gb | 8 | 1024 |
